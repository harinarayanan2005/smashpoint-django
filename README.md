# SMASHPOINT — Pro Badminton Store

A modern full-stack e-commerce web platform for professional badminton equipment, featuring 3D WebGL court aerodynamics, multi-filter catalog browsing, and full checkout order processing.

## 🏸 Tech Stack
- **Backend**: Python 3.11+, Django 5.2+ (MVT Architecture, SQLite ORM)
- **Frontend**: JavaScript (ES6+), Three.js (WebGL 3D Waves)
- **Design**: Vanilla CSS3 Custom Dark Court Design System
